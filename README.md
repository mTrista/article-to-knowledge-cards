# make-knowledge-cards

## 项目解决什么问题

读完一篇文章后，整篇重读往往不方便。这个 Codex Skill 把值得记住的内容整理成可以逐张复习和自测的知识卡片。

## 主要功能

- 接受粘贴的文章正文，或指定的本地 Markdown（`.md`、`.markdown`）和 TXT（`.txt`）文件。
- 合并重复内容，每张卡聚焦一个知识点。通常生成 5–8 张，知识点不足时按实际数量输出。
- 每张卡包含标题、核心知识、简明解释，以及原文例子或自测问题。卡片以原文为依据，保留重要条件和例外。

输出为 Markdown 文本。网页链接或 PDF 需要先提供正文。Anki 导出和图形界面暂不支持。

## 安装方法

从项目根目录将整个 Skill 文件夹复制到 Codex 用户技能目录。

```sh
mkdir -p ~/.codex/skills
cp -R skills/make-knowledge-cards ~/.codex/skills/
```

## 使用方法

在 Codex 中输入以下任一请求。使用相对文件路径时，以当前工作目录为起点。

- 粘贴正文：`用 $make-knowledge-cards 把下面的文章做成知识卡片。` 然后附上正文。
- 指定文件：`用 $make-knowledge-cards 将 ./notes/reading.md 做成知识卡片。`

默认沿用正文语言，也可以在请求中指定输出语言。

## 输入与输出示例

**输入**

> 对于固定时长的复习，把练习分散到几天内，比集中在一天内更有利于长期记忆。

**输出**

```markdown
## 分散练习
- **核心知识**：复习总时长相同时，分几天练习更有利于长期记忆。
- **简明解释**：两种安排使用相同的复习时间，区别在于练习是否分布在多天。
- **自测问题**：复习总时长相同时，怎样安排练习更有利于长期记忆？
```
